# Enflix

A Netflix + Prime inspired movie watching website built with Next.js.

## Features

- **Auth System** — Sign up, login, JWT sessions
- **Movie Catalog** — Browse by genre, hero banner, movie detail pages
- **Video Player** — Fullscreen player with controls
- **Watch Together** — Create party rooms with shareable links and live chat

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Tech Stack

- Next.js 16 (App Router)
- Tailwind CSS
- JWT + bcrypt authentication
- JSON file storage
